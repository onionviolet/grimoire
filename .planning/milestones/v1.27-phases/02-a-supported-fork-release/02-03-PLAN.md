<objective>
Close the last experimental surface that its own setting does not actually gate, and stop a shipped document claiming a capability the project forbids claiming.

Purpose: `src/App.tsx` mounts the Chat Wheel route unconditionally, and `src/pages/ChatWheel.tsx` never reads `experimentalChatWheel`. The sidebar entry is gated correctly, so the setting looks like it works while any direct navigation walks straight past it. Output: a page-level gate matching the one precedent this codebase already uses, a render test covering all three states of the setting, and a spec document that agrees with the app.

## Scope this plan deliberately does not take

Per Pitfall 5 in RESEARCH.md, this plan does NOT add conditional logic to `src/App.tsx`'s route table and does NOT touch `src/components/Sidebar.tsx`. Every experimental page in this codebase self-gates with an early-return `EmptyState`, and the sidebar filtering at `Sidebar.tsx:516` is a separate, already-correct concern. A diff touching either file for this fix is the wrong fix.

No new setting is introduced. `experimentalChatWheel` already exists in `src/types/mod.ts` and already has a toggle in `ExperimentalSection.tsx`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL or deep link to page render | A route can be reached by typing a hash, following a stale bookmark, or a protocol handoff. The page component is the only thing standing between that navigation and an experimental surface. |
| renderer store to page state | `settings` arrives asynchronously from the main process; the page renders at least once before it exists. |
| repository docs to user expectation | `docs/profile-spec.md` is a shipped document; a claim in it is a claim the project makes. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-02-03-A | Elevation of privilege | `src/pages/ChatWheel.tsx` route reachability | medium | mitigate | The guard lives in the page component, so every path to the page (URL bar, bookmark, deep link, programmatic navigate) passes through it.
