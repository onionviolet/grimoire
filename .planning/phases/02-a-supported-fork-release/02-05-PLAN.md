## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local repository to origin | `git push origin --delete` removes a ref from a server this repository cannot restore it from. |
| reflog retention window | A deleted local branch is recoverable from the reflog only until it expires. |
| worktree to branch deletion | A dirty worktree holds uncommitted work that a forced removal would destroy without review. |
