<objective>
Move every fork-owned support destination to GitHub Issues on `onionviolet/grimoire`, and prove in an automated guard that the attribution surfaces were not swept up with them.

Purpose: a user handed this build must be able to ask for help somewhere that can answer. Today the update modal offers only the upstream project's chat channel, and the Settings support section offers it beside the fork's own tracker as if the two were equivalent. Per D-03 the fork's support destination is GitHub Issues on `onionviolet/grimoire`.

Output: three call sites moved, four surfaces deliberately untouched and locked down by a test, the decision written into `docs/fork-maintenance.md`.
