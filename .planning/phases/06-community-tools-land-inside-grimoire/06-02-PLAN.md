<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pending-download map to `browser:resolve-tool-download` | A renderer-supplied id selects which file gets imported |
| refusal reason string, main to renderer | Main-authored text rendered into the page |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-07 | Spoofing | `resolvePendingToolDownload` id lookup | high | mitigate | Confused deputy: a resolve arriving for a superseded id must not cash against the newer file. The id is removed from the map as the first action after a successful lookup, replacement deletes the old entry outright, and every absent-id path returns stale and imports nothing. Unit tested for double resolve, never-issued id, and post-replacement resolve. |
| T-06-08 | Tampering | replaced or interrupted temp file | medium | mitigate | Every terminal path (refused, failed, replaced, declined, imported) deletes the temp file. Tests assert non-existence on the refusal and replacement paths. |
| T-06-09 | Information Disclosure | refusal reason rendered in the page | low | accept | `describeVpkRejection` composes its sentence from a caller-supplied display name and a fixed format label. The display name originates from the guest's `download` attribute, so it is attacker-influenced text, but React escapes it on render and it is never used as a path, a selector, or a shell argument. |
| T-06-10 | Denial of Service | repeated Build VPK clicks | low | accept | Replace-newest bounds the pending set at one entry and deletes superseded bytes immediately, so a click loop consumes one file's worth of disk rather than growing without limit. Chromium's own download manager rate limits the writes. |
| T-06-SC | Tampering | npm/pip/cargo installs | high | accept | No packages are added by this plan. RESEARCH.md's Package Legitimacy Audit records zero new dependencies, so there is no install task to gate. |
</threat_model>
