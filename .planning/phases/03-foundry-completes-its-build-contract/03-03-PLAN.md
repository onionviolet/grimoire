<planner_decisions>
- **Second mount point, not a duplicate flow.** The staged-edit id produced by `prepareRecolorStagedEdit` is derived from the hero alone, and `Foundry.tsx` and `HeroWorkshop.tsx` both dedupe staged edits by id. Staging from the workshop Appearance section and from the Recolor sub-tool for the same hero therefore produces one tray row, not two.
- **`FoundryBuildTray.tsx` is untouched.** It already maps every `FoundryEditKind` to an i18n key, and `foundry.buildTray.kind.recolor` already exists. Adding it to this plan's file list would create a phantom dependency.
- **The Body plus Gun caption is not scope creep.** `TrippySkinPanel` keeps its behaviour exactly; the only change is one caption line, which exists because its sibling tab's behaviour changed underneath it. Without it the panel reads as inconsistent, which is the RESEARCH pitfall this plan is closing.
</planner_decisions>
