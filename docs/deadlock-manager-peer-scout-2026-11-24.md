# Deadlock mod manager peer scout

> **Research · November 24, 2026.** Compared peer documentation, source entry points and community reports with fork checkout `2d873ce9`. The baseline is the internal candidate. These are proposals. No peer binaries or game sessions were run.

The [November 25 candidate reconciliation](internal-release-note-2026-11-24.md#november-25-candidate-reconciliation)
records the local implementation and remaining acceptance for F1 through F4.

## Ranked opportunities

| ID | Recommendation | Evidence, scope and acceptance |
| --- | --- | --- |
| F1 | **Trial a Foundry control to restore stock VFX on one skin.** | A DMM user asked to keep a Paige model while replacing its custom ability effects with stock. HELLCAT documents a related pattern: adjust individual skin parts and write a separate overlay VPK. Grimoire already detects and extracts single-hero particle layers and has reviewed merge recipes. Start with one mixed Paige pack, show the affected paths and unresolved dependencies, and stage a reversible build. Medium effort. Confirm the model and sound stay modded, stock effects render in a private game, input bytes stay intact, and undo restores the original effects. [Discord request](https://discord.com/channels/1322369530386710568/1322369721546309685/1573925460776194220) · [HELLCAT](https://gamebanana.com/tools/24446) · [Grimoire VFX layer](ability-vfx-recolor.md) |
| F2 | **Adapt DMM's plain-language broken-mod entry point.** | Users asked where to get help after a camera break, whether a crash dump can name a mod, and how to diagnose launch failures. Grimoire already has crash history, patch evidence, installation checks, and assisted isolation that can retain an interacting group. Link a clear **Find a broken mod** action from post-launch help and Installed to that existing flow. Show the baseline scope and a next action when the baseline also fails. Small UI change, with native verification. Test navigation from a crash with a suspect, a generic crash, and an issue reported without a dump. [DMM guide](https://docs.deadlockmods.app/using-mod-manager/finding-a-broken-mod) · [Camera support](https://discord.com/channels/1322369530386710568/1322369721546309685/1573524016931676322) · [Crash dump question](https://discord.com/channels/1322369530386710568/1322369721546309685/1572978042563985471) · [Grimoire Recovery](setup-evidence-and-auditions-2026-10-03.md) |
| F3 | **Trial an author check for the ZIP players receive.** | An author could see a model in a manager preview but reported no in-game result. Another asked how to package a VPK for manager-compatible distribution. S2ModKit exposes explicit compatibility scans and package verification with structured reports. Grimoire already inspects exact model entries and reviews Foundry builds. Add a read-only check of one release archive against the actual installer and selected game build, with a copyable report for bad archive contents, missing in-scope references and covered mount conflicts. Medium effort for one archive and asset class. Use a known-good hero skin plus fixtures for an archive missing a dependency and a mounted higher-priority VPK winning the same path. Confirm the check distinguishes a viewable model from a verified package and labels anything that still needs an in-game test. [Preview vs. game](https://discord.com/channels/1255127939989766184/1270469868059361300/1573877885964386436) · [Packaging question](https://discord.com/channels/1255127939989766184/1270469868059361300/1571011343908216935) · [S2ModKit CLI](https://github.com/Ainzak/Source-2-Mod-Kit-for-DeadLock/blob/3cca21066611b441a32e63f5830bc1b18f6b6846/docs/CLI-REFERENCE.md) · [Grimoire inventory](feature-status.md) |
| F4 | **Adopt Duplicate profile as a small convenience.** | A DMM user wanted core mods shared across setups and reported that copying meant redownloading or manually porting files and losing GameBanana update checks. Grimoire already saves profiles as references to a shared installed library. Creating from the active setup covers part of the request. Add duplication of a saved, inactive profile with a new identity and copied selections. Small effort. With networking disabled, duplicate an inactive profile containing a local mod and a GameBanana variant, apply it through review, and verify both profiles can be edited independently with no archive downloads or file duplication. [Discord discussion](https://discord.com/channels/1322369530386710568/1322369721546309685/1574315365087846472) · [DMM profile model](https://docs.deadlockmods.app/using-mod-manager/profiles) · [Grimoire profile implementation](../electron/main/services/profiles.ts) |

F2 is the smallest broad support improvement. F1 is the strongest addition to Grimoire's customization workflow. The HELLCAT pattern is documented by its author. The stock VFX operation, implementation estimates and acceptance checks above are proposals.

## Other signals

- DMM nightly testers reported the store and Installed views disagreeing about current file versions, including repeated update prompts. A maintainer reproduced a cache problem. This is a regression case to try against Grimoire's own installed-file identity and update flow if an equivalent report comes in. Linux helpdesk also had recent Steam Deck detection and Mint packaging or launch reports. Collect the failing stage and selected Steam library through the existing Recovery path before changing packaging. [Cache discussion](https://discord.com/channels/1322369530386710568/1557044693211160706/1563474095537135617) · [Steam Deck report](https://discord.com/channels/1322369530386710568/1470108603598766304/1574551589610463263) · [Mint launch report](https://discord.com/channels/1322369530386710568/1470108603598766304/1574905424925171914)
- DMM implements custom mod sources and GameBanana remote installs. An open request proposes a reviewed source directory with catalogs fetched only after a click. Park this until a specific publisher or device workflow matters to Grimoire. The existing Forge bridge covers an opt-in install from that source. A general catalog needs source identity, update semantics and a privacy entry. [DMM releases](https://github.com/deadlock-mod-manager/deadlock-mod-manager/releases) · [Directory proposal](https://github.com/deadlock-mod-manager/deadlock-mod-manager/issues/1423) · [Remote install](https://docs.deadlockmods.app/using-mod-manager/remote-install) · [Grimoire bridge](../electron/main/services/forgeBridge.ts)
- Shiv publishes a reproducible Browse memory measurement and caps thumbnail retention. Borrow the workload to measure Grimoire before choosing a cache change. Grimoire already has download-cache review, which is separate from decoded thumbnail memory. Hideout's friend-code hosting is a distinct capability. Park hosting unless the fork wants to own local server setup and support. The existing Deadworks browser covers joining a community server and provisioning its content. [Shiv benchmark](https://github.com/Siebe-Uy/shiv/blob/21333cf620cddeebf9b90dd1a2676b0e78935a35/docs/perf-results.md) · [Hideout](https://github.com/hideouthq/hideout/tree/79ea54506ac8e2b210efd31c4bdb0cc7094306a9) · [Deadworks](deadworks-servers.md)
- Small-manager references mostly duplicate the candidate's archive install and profile workflows. Simple Deadlock Mod Manager does offer per-operation backup metadata and an undoable rollback, which is worth comparing if per-file recovery becomes a named gap. HELLCAT users also asked for easy config toggles they had in Grimoire. [Simple Deadlock Mod Manager](https://github.com/OzanKutlar/ModManager-Deadlock/tree/fcbfa9cece8e561f17694943a8f8e18c35d188fc) · [Earlier Windows manager](https://github.com/Tylevo/DeadlockModManager) · [HELLCAT comments](https://gamebanana.com/tools/24446)

## Coverage and reuse

Discord coverage included DMM general, Linux helpdesk, nightly and developer chat, plus Deadlock Modding support and searches for other managers. General and support searches focused on November, with older nightly and named-manager discussions also sampled. Discord denied access to the dedicated DMM suggestions and bug-report forums through the connected tool. Public GitHub issues and GameBanana comments provided additional evidence. Tome appeared in listings and community chat, with insufficient primary feature evidence to rank. Individual comments show concrete cases, and the sample gives no reliable estimate of prevalence.

The shortlist borrows workflows and acceptance checks. S2ModKit is MIT at the linked revision, with separate dependency notices. DMM, Shiv and Hideout are GPL-3.0. HELLCAT's feature evidence came from its published description and comments. Use Grimoire's existing code for the proposed implementations.
