# Grimoire

Desktop mod manager for Deadlock (Valve). Electron 44 + React 19 + TypeScript 5.9 + Tailwind 4, pnpm. Ships for Windows, Linux (AppImage, deb, AUR, Flatpak) and macOS (Apple Silicon only, ad-hoc signed, no auto-update: see `docs/macos.md`).

Single maintainer. Part of the `grimoire-workspace` monorepo-ish root; sibling repos (`../grimoire-social`, `../vpkmerge`, ...) have their own `AGENTS.md`/`CLAUDE.md`. This workspace is the fork `onionviolet/grimoire`.

## GitHub boundary

- `origin` (`onionviolet/grimoire`) is the only repository you may change. `upstream` (`Slush97/grimoire`) is read-only: fetching is fine, mutating it is not. Push only to `origin` unless the user authorizes another remote.
- Every mutating `gh` or API command names `--repo onionviolet/grimoire`. State the exact `owner/repository` and object number first.
- Never write upstream issue or PR numbers in GitHub-facing text (commits, issue/PR bodies, comments, release notes). Record provenance in `docs/`.
- A task that needs an upstream change: stop and ask.

## Commands

`pnpm dev` (parallel agents: always `GRIMOIRE_DEV_SLOT=<n> pnpm dev`, never unslotted), `typecheck`, `lint`, `test`, `ui:check`, `encoding:check`, `refs:check`, `i18n:check && pnpm i18n:manifest` (after any locale change), `build` (needs `GRIMOIRE_SOCIAL_BASE_URL`, any URL works locally), `package:linux | package:win | package:mac`. Native rebuilds and the full list: build-packaging doc.

## Hard rules

- **No em-dashes**, anywhere: UI strings, comments, docs, commit messages. Replies too. Use a colon, period or parens.
- **No telemetry.** A new network request needs an entry on the privacy guide page, and an off switch if it sends user data somewhere the user didn't choose.
- **Main process owns secrets.** API keys and the social session token never reach the renderer.
- **Wire-format types come from `@grimoire/social-types`.** Never redeclare them. Social routes are `/v1/*`, additive only.
- **External APIs go through the rate limiter** in `electron/main/services/rateLimiter.ts`.
- **The portable profile format is Grimoire-only.** Don't claim compatibility with other mod managers.
- **Visible strings are i18n keys.** Never hardcode user-facing copy.

## Done means

Before calling a change done: `pnpm typecheck && pnpm lint && pnpm test` (plus `pnpm ui:check` for renderer UI). CI (`.github/workflows/ci.yml`) runs lint, the `ui:check` design-system ratchet, `tsc -b`, vitest, the i18n gates, then `electron-vite build`. The husky pre-push hook also runs encoding, upstream-reference, UI and engine-pin gates.

Commits: imperative, conventional-style subjects (`fix(installed): ...`, `feat: ...`). PRs are squash-merged. Branch protection has no required checks, so `gh pr merge --auto` merges immediately: check `gh pr checks` first.
